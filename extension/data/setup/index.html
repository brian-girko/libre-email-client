Remote WS server

Enter the address of a running ws → TCP/TLS bridge server. The server must speak the ws-to-tls protocol.

Runs standalone on any Node.js: node ws-to-tls.js --ws-port 8080 — paste the printed ws:// URL below.
Test target

The test connects to your server and asks it to dial this TCP target. Any reachable host proves tunneling works; your IMAP server is the best choice.

Installation

  1. Extract the downloaded windows.zip.
  2. Run install.bat from the extracted folder. It uses your installed Node.js (>= 6) or downloads one automatically, then registers the host for Chrome, Edge, Firefox and friends.
  3. Uninstall any time with uninstall.bat.
  1. Extract the downloaded linux.zip.
  2. Run ./install.sh from the extracted folder. It uses your installed Node.js (>= 6) or downloads one automatically, then registers the host for your browsers. Optional: ./install.sh --custom-dir=~/Desktop/.
  3. Uninstall any time with ./uninstall.sh.
  1. Extract the downloaded mac.zip.
  2. Run ./install.sh from the extracted folder. It uses your installed Node.js (>= 6) or downloads one automatically, then registers the host for your browsers.
  3. Uninstall any time with ./uninstall.sh.
