Remote WS/TS Bridge

The bridge connects the extension to your IMAP server over WebSocket.

Sample NodeJS Bridge

The bridge ships inside this extension as core/ws-to-tls/ws-to-tls.js — a zero-dependency Node script (Node 16+; uses only the net/tls/crypto built-ins).

Download it (button below), then run:

node ws-to-tls.js --ws-port 8080

It prints its URL, e.g. ws://127.0.0.1:8080/<random-token> — paste that exact URL into the extension's options page. The token in the URL path is the server's only access control.

Notes

  • The bridge can be written in any language — the protocol is simple: receive {op:'open', host, port, secure} as a text frame, reply with {op:'ready'} or {op:'error'}, then tunnel binary frames.
  • Useful when multiple users on a network share one bridge.
  • Useful when you cannot install native apps on the user's computer.
  • Configure the bridge URL in the extension's options page.
